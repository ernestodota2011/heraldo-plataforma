# apps/web — marcador de posición

Aquí va el frontend: el **panel de la agencia**, el **portal de cada cliente**
con su marca y el **widget** — Next.js (App Router) + TypeScript + Tailwind +
shadcn/ui, decisión **D-06**.

Todavía no hay nada: lo construyen sus tareas dueñas, en su fase. Este archivo
existe para que el directorio esté en el repositorio y para que nadie levante
aquí un segundo frontend por creer que el sitio no tenía sitio.

**Nada que hable con el canal de mensajería o con la red sale de aquí**: toda
salida pasa por `packages/egress`, sin excepción y sin segundo camino.
